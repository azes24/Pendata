# Visualisasi Data

Visualisasi data adalah proses menyajikan data dalam bentuk grafik, diagram, atau gambar agar informasi lebih mudah dipahami, dianalisis, dan diinterpretasikan. Dengan visualisasi, pola, tren, perbandingan, dan hubungan antar variabel dapat terlihat lebih jelas dibandingkan hanya melihat angka dalam tabel.

# Contoh Visualisasi Data

## Scatter Plot

Digunakan untuk melihat hubungan antara dua variabel numerik. kita dapat mengecek menggunakan aplikasi orange dan import data yang akan divisualisasikan, disini sebagai contoh menggunakan data IRIS.

## Histogram

Histogram adalah grafik yang digunakan untuk menampilkan distribusi frekuensi data numerik dengan cara membagi data ke dalam beberapa interval (disebut bin atau kelas).
